# viewer:「调用约定」视图

## 问题

viewer 能点「一键优化」「lower」改图,但改的是**这张图内部**。而调用方看到的
不是这张图 —— 是复合节点**对外的那个节点**:左边参数、右边返回值、控制流
引脚在两侧最上面。

于是有两件事看不见:

- 优化把某个参数消掉之后,**调用方那个节点上的引脚也会少一个** —— 图上看不出这个后果;
- 返回值可能不是"函数体算出来的",而是**原样透传某个参数**(`ret = x`)或者
  一个常数。这两种在图上分别表现为"出口直接接参数"和"出口只带默认值",
  但它们在对外的节点上看起来完全一样(`Export N` 桩线)。

## 视图

打开一张**复合节点图**(一个函数)时,右栏上半多一个面板,画成**内外两层**:

```
┌─ 外层:加载时的调用节点(冻结)──────────────┐
│ x <Int> ●─────────────────┐                 │
│ y <Int> ●────────────┐    │        ● z <Int> │
│ ▲(控制入)        ┌───▼────▼───┐     ▲        │
│                  │   当前      │     │        │
│                  └──┬──────┬──┘     │        │
│                     └──────┴────────┘        │
└──────────────────────────────────────────────┘
```

- **外层**:加载 `.ogia` 那一刻的接口,**冻结,永不改变** —— 代表调用方看到的节点。
- **内层**:当前状态,画成**一个普通节点**(和画布上那些一样),**可以在外层里拖动**,
  拖不出外层。

主图不显示这个面板 —— 主图没有"调用约定"(没人调用它)。

## 连线规则

外层的每个**数据流出引脚**按当前状态连成三种形态之一:

| 形态 | 意思 | 连线 |
|---|---|---|
| 函数体算出 | 返回值由某个节点产生 | 外层出引脚 ← **内层**出引脚 |
| 参数透传 | 函数原样把某个参数还回去 | 外层出引脚 ← **外层**入引脚 |
| 常数 | 返回值是个字面量 | 写在内层节点旁边,没有线 |

控制流引脚同理:当前函数体**有**控制流就连到内层,**没有**就直接从外层控制入
横穿到控制出。

外层里已经没有对应内层引脚的参数 / 返回值 = **已被优化消掉** —— 它们不再连线,
但在 `Convention::dropped_params` / `dropped_rets` 里能查到。

### 引脚没了、值还在

`lower` 的 `compact_value_exports`(`core/src/compile/optimize.rs:617`)会摘掉
**没人读**的值出口。**直接返回常数**的函数正是这样:出口没有节点读,值只留在
`decl.proxies_out` 里(`optimize.rs:621`,那份表在压缩**之前**建,下标是原始
出引脚序号)。于是内层连那个引脚都不剩。

但这仍然是**调用方看到的那个返回值**,值也确实存在 —— 必须照样画。所以
`FnInterface::orphan_rets: Vec<(原始引脚下标, OrphanRet)>` 把 `proxies_out`
读出来:

- `Some(Right(Some(v)))` → `OrphanRet::Const`,画在内层节点右侧;
- `Some(Left(j))` → `OrphanRet::Param(j)`,照旧连到外层第 `j` 个入引脚
  (记原始下标,因为参数表同样会被压缩,那时按名字已经找不到了);
- `None` → 出口还在,那一轮已经给出准确来源。

`conv::Constant::inner` 因此是 `Option<usize>`:有内层引脚就对齐那个引脚,没有
(`None`)就从内层顶端往下排。用户报的「直接返回常数的你没有显示」就是漏了这条。

## 数据来源

| 数据 | 来源 | 为什么 |
|---|---|---|
| 外层 | `Doc::frozen`(加载时存一份) | 加载之后没人保留原始 `exports` 表;优化会压缩引脚、撤销会换图 |
| 内层 | `GraphEntry::interface`(每次 `reflatten` 重算) | 优化 / lower / 撤销都会 `reflatten`,这里跟着更新 |
| 返回值来源 | `externals.values_in[i].link` | 出口的来源槽:接节点 = 函数体、接 `Export` = 参数、只有 default = 常数 |
| 出口没了的值 | `FnDecl::proxies_out` | `compact_value_exports` 只把值留在这份表里,下标是原始出引脚序号 |

## 配对必须按名字

内层引脚配到外层引脚时,**按名字**而不是下标(`conv::match_by_name`)。

优化会压缩引脚(`Optimizer::compact_value_imports` /
`compact_value_exports`),**下标会移位**,名字不会。按下标配的实现在一次优化
之后就会张冠李戴。

## 引脚靠上排,值流起点跨两侧取最大

两个都是用户提的,而且都落在 **core 的共享几何**里(`core/src/node/layout.rs`),
因为画布、「调用约定」视图、`.gia` 的自动整理用的必须是同一套:

- **引脚靠上,不居中** —— `pin_row_y(row) = PIN_TOP + row × PIN_GAP`,
  首个引脚在 `PIN_TOP`(=`PIN_GAP/2`),末行到节点底部也只留 `PIN_TOP`。
  以前是"整条边 `N+1` 均分",一行也居中、十行也居中。
  `node_height(rows) = max(NODE_H, rows × PIN_GAP)` —— 行距是**定值**,
  不再是"高度除以行数"。

- **首个数据流引脚跨两侧对齐** —— `pin_rows(ctrl_in, value_in, ctrl_out, value_out)`
  里 `value_start = max(ctrl_in, ctrl_out)`。两侧各算各的话,控制流数量不同时
  左右第一个值流引脚会错开一格,看起来像数据从半空接过去。
  控制流引脚本身仍从第 0 行开始,各自有几个排几个(它们本来就不成对)。

## 层级与引脚排布:和画布共用同一套

调用约定的视图和主画布是**两个视图**,但引脚的排布和绘制顺序必须**一致** ——
否则同一个函数在两处看起来不一样。

- **引脚排布共用 [`view::pin_y`]** —— `conv::pins_on_side` 直接调它,
  不自己写一份。(自己写的那份和画布的档位算法一致,但一旦有人改了
  画布那边,两边就会漂开。)
- **绘制顺序**由 `conv::LAYER_ORDER` 声明:`边 → 外层盒子 → 内层节点 →
  引脚 → 文字 → 悬停气泡`。

  ⚠️ **引脚必须在盒子之后** —— 内层节点是不透明的(`node_bg()`),引脚先画
  就被它盖住,表现就是"引脚被自己遮挡了"。这和主画布的顺序一样
  (那边也是「节点 → 引脚」)。

## 引脚名在外侧,类型只在悬停时出现

- 外层的参数名 / 返回值名画在盒子的**外侧**(左边右对齐贴盒子左边,右边左对齐贴盒子右边),
  盒子左右各留一条 `LABEL_GUTTER` 给它们。
- 名字**只写名字**,不带类型 —— 类型在**悬停气泡**里:
  - 悬停引脚 → `名字 <类型>`;
  - 悬停连线 → 两端各自的类型(`x <Int> → y <Bool>`)。
- 命中测试在 `conv::hit_test`:引脚优先于连线(引脚是小目标、又压在连线上),
  半径 `PIN_HIT_R = 8` / `LINK_HIT_R = 6`,**不随缩放变**(这个视图固定 1 倍缩放)。
- 内层**不写引脚名** —— 它是"一个普通节点",普通节点上不写引脚名;
  而且两层挨得近,名字叠在一起反而读不出来。

## 测试

`conv.rs` 的单元测试锁住:按名字配对、三种返回值形态、控制流贯穿 vs 连内层、
掉参、内层拖不出外层、外层装得下内层、**优化之后内层跟着变**。

`doc.rs` 的单元测试锁住:接口抽得出来、主图没有冻结接口、`is_fn_graph` 的判据、
**冻结的外层不随优化改变**、三种 `RetOrigin`、**`lower` 之后直接返回的常数
仍然在**(`a_constant_return_survives_lowering`:出口引脚清零 + `proxies_out`
留值 → 常数出现在 `Convention::constants` 且**拿到坐标**)。

## 已知限制

- 只按**名字**配对。两个参数同名(真实 IR 里不该出现,但 `.ogia` 是用户拖进来的)
  时退化到按顺序配。
- 内层的引脚位置是**自己算的**(按它自己的 pin 数均分),不是从画布那份几何
  搬过来的 —— 这个视图有自己的坐标系,不跟画布的平移缩放走。
- 常数只显示 `Debug` 文本,不区分类型。
- 出口已被摘掉的常数没有内层引脚可以对齐,只能从内层顶端依次往下排;多个
  这种常数挤在同一侧时是**按顺序**放的,不对应任何内层引脚。
